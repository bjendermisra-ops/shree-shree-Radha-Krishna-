The artwork **is not documentary photography** of the mandir exterior, its real visitors, actual celebrations, or today's real darshan. Art captions and image alternative text must keep this distinction clear. Do not infer exact Ekadashi dates from an illustration or from a sample app screenshot.

## Ownership and content protection

Website source files and text are copyrighted by their respective owners. No open-source grant is made by the existence of a public GitHub repository. Reusing image files from a repository owned by the same account does not establish third-party copyrights; the repository operator should verify the rights to use and republish each image.

A public website necessarily transmits images and code to visitors, so technical blocking cannot guarantee nobody copies or screenshots them. Browser keyboard/context-menu blocking is deliberately avoided because it harms legitimate users and accessibility. Maintain ownership notices, original asset records, and security headers; use a private GitHub repository if source-code secrecy is required.
